# ケロちゃん あたま ぐんぐん

ケロはかせと いっしょに、まいにち すこしずつ あたまの たいそうを する ゲームです（5〜6歳向け。おとなも遊べます）。
「脳を鍛える大人のNintendo Switchトレーニング」のしくみ（毎日のチェック・トレーニング・スタンプ・グラフ）を、
「ケロちゃん もぐもぐ」「ケロちゃん ぴよぴよポン」と同じキャラクター・雰囲気で、小さな子ども向けに作り直しました。
ブラウザで動き、Android の Chrome から「アプリとしてインストール」できます（PWA）。設計は `DESIGN.md` にあります。

- **きょうの チェック**：はやさ・きおく・がまん の3つのテストで、きょうの あたまを どうぶつで あらわします（おとなのユーザーは「のうねんれい 20〜80さい」）
- **トレーニング 12しゅるい**（かんたん・ふつう・むずかしい、おとなは「おとな」も）
  - はやさ：けいさん／いちばん おおきい かず／じゅんばん ぴょんぴょん
  - きおく：ぱっと おぼえて／なんにん いるかな？／さっきの え
  - がまん・しゅうちゅう：あとだし じゃんけん／ジャンプで タッチ／とり かぞえ
  - もじ・おと・パズル：ことば つくり／ピアノ／えあわせ すうどく
- 結果は どうぶつ7だんかい（かたつむり → かめ → ペンギン → カンガルー → うま → チーター → はやぶさ）と ★（★3は ミスなしの ときだけ。はんぶん いじょう まちがえると ★1）
- **スタンプ**：1日1こ。5こごとに はなまる。スタンプが たまると トレーニングや ピアノの きょくが ふえます（8こで トレーニングが ぜんぶ、20こで きょくが ぜんぶ）
- **きろく**：チェックと トレーニングの グラフ（グラフに のるのは その日 さいしょの 1回）
- **おみせ**：あつめた★で ミミちゃん★10・ニャーちゃん★20・ワンちゃん★30（あいぼうになって いっしょに あそびます）
- **ふたりで**：1台のスマホを むかいあって 2人で たいせん（とり かぞえ・はこ かぞえ・あとだし じゃんけん）。おとなは すこし まってから こたえられます
- **こえ**：ケロはかせが ずんだもんの声（VOICEVOX:ずんだもん）で しゃべります（タイトルの ふきだしボタンで オン／オフ）。なまえ（ニックネーム）は ふきだしに 書くだけで、よみあげません
- 画像と効果音・音楽は ファイルを使わず、すべてプログラムで描画・合成しています（ファイルは ケロはかせの声だけ）

## おうちの方へ

- ケロちゃん ランド（メニュー）で決めた なまえ（ニックネーム）で、ケロはかせが よびかけます（かぞくモードで名前を付けたユーザーは、その名前）
- ことば：ケロちゃん ランド（メニュー）の 地球のボタンで 日本語・ベトナム語・英語・韓国語を えらべます（ぜんぶの ゲームが その ことばに なります。`localStorage` の `kero-lang`）
- 日本語以外では、ケロはかせの セリフを スマホの よみあげ きのう（その ことばの 声）で しゃべります（ずんだもんの声は 日本語だけ）。ことば つくりは その ことばの 文字（英語＝アルファベット、韓国語＝ハングル、ベトナム語＝声調記号つきの文字）で 作ります

- タイトル画面左上の家のボタンで、ゲームのメニュー「ケロちゃん ランド」（https://manhtuan87.github.io/）に もどれます
- タイトル画面左上の ⚙ → 管理者パスワード（123）で、管理者メニューが開きます
  - ユーザー（かぞくモード）：4人まで。名前・こども／おとな・色を決められます。2人以上いると、起動時に「だれが あそぶ？」が出ます
  - 全トレーニング解放：スタンプを待たずに、すべてのトレーニングと曲を遊べるようにします
  - おしまいの声かけ：1日に 3つ（または 5つ）やると「きょうは このへんで」と声をかけます。しない こともできます
  - このユーザーの記録をリセット
- なまえの読み上げ（と、声のファイルが使えないとき）は Android の「テキスト読み上げ」の日本語の声を使います。なまえを しゃべらないときは、設定 → システム → 言語と入力 → テキスト読み上げ で日本語の音声データを入れてください
- ベトナム語・英語・韓国語の声も Android の「テキスト読み上げ」を使います。しゃべらないときは、同じ所で その ことばの 音声データを入れてください（管理者メニューに 見つかったかどうか 出ます）
- 記録は この端末の中（ブラウザ）だけに保存されます

## PC で試す

```
python tools/serve.py 8768
```

ブラウザで http://localhost:8768 を開きます。**パソコン（localhost）では、テストのじゃまに ならないよう 音も声も出ません。**
音を確かめたいときは http://localhost:8768/?sound=1 を開いてください。

## 開発メモ

- 多言語：`js/lang.js`（全ゲーム共通。日本語の文をキーに `L('日本語', {変数})` で訳を引く）と `js/lang-text.js`（このゲームの訳：[ベトナム語, 英語, 韓国語]）。新しい文言を足したら4言語そろえる
- 言語ごとに変わる中身（ことば つくりの単語・文字・長さ、じゅんばんの文字、ピアノの音名、カレンダーの曜日）は `js/lang-text.js` の `GUNGUN_LANG`。`app.js` の localize() が起動時にデータへ入れる。結果の文は数値で記録し（`U.res`）、表示のときに訳す

- `js/app.js` … 画面・チェックの流れ・結果・スタンプ・記録・おみせ・管理者・メインループ
- `js/core.js` … セーブデータ（ユーザー別）・日付・スタンプ・解放・ランク・脳年齢（Node.js のツールと共通）
- `js/data.js` … どうぶつ・トレーニング一覧・絵の名前・ピアノの曲（著作権の切れたメロディーだけ）・ケロはかせのセリフ
- `js/trainings.js` と `js/tr/*.js` … トレーニング1つ＝1ファイル。問題作り（`gen`）と遊ぶ部分（`start`）
- `js/versus.js` … ふたりで（画面の上半分は さかさま）
- `js/draw.js` … ぴよぴよポンのキャラクターの絵（小物と台なしの描画を追加）、`js/art.js` … どうぶつ・じゃんけん・スタンプなど、`js/pics.js` … 絵27しゅ
- `js/sound.js` … 効果音・ピアノ・BGM
- `js/voice.js` … ケロはかせの声。日本語は 決まったセリフが `voice/` の声のファイル（Ogg Opus）、なまえだけ スマホの読み上げ。ほかの ことばは ぜんぶ スマホの読み上げ（しゃべる文は `L()` で その ことばに してから渡す。声だけの セリフも `js/lang-text.js` に 訳が要ります）。`js/voice-clips.js` は セリフ→ファイルの一覧（自動で作るので手で直さない）
- 声の作り方：`tools/voice/lines.js` に しゃべるセリフ（と、自然に読ませるための漢字の読み方）が全部あります。セリフを変えたら VOICEVOX を起動して `node tools/voice/make.js`（ffmpeg が必要。`--ffmpeg パス` で指定もできます）。変わったセリフだけ作り直し、使わなくなったファイルは消します
- `tools/voice-test.html?sound=1` … 音を出さずに、声の順番（なまえ→セリフ）と 全部の声のファイルが読めるかを確認
- `node tools/verify.js` … 全トレーニングの問題作りを各レベル数百回ずつ動かして確認（答え・範囲・重なり・すうどくの答えが1つ・セーブの読みこみ など）
- `tools/gallery.html` … すべての絵を1ページに並べて確認
- `tools/autoplay.js` … ブラウザで全トレーニングを自動で遊ばせる確認用（コンソールで読み込む）
- アイコンは `tools/icon.html` を `tools/make-icons.ps1`（ヘッドレス Chrome）で PNG にしています
- 更新を配信するときは `sw.js` の `VERSION` を上げてください（アプリを開いたとき・アプリに戻ったときに新しい版を探し、見つかったら サーバーから直接 取り直して、タイトル画面で自動的に読み込み直します）。同じサイトの他のゲームと混ざらないよう、`gun-` で始まるキャッシュだけを消します
